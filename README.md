## Практична робота 2: Дослідницький аналіз і підготовка даних
* **Мета:** Дослідження структури та якості табличних даних, виявлення й усунення пропусків, дублікатів, неправильних типів даних і аномалій, кодування категоріальних ознак та формування вибірок для машинного навчання.
* **Основні результати:**
  * Створено контрольовано пошкоджений набір даних `iris_dirty.csv`.
  * Проведено аудит якості даних, виявлено пропуски, аномалії та зайві дублікати.
  * Виконано очищення даних, заповнення пропусків медіанами та модою.
  * Закодовано категоріальні ознаки та цільову змінну (`species`).
  * Сформовано та збережено стратифіковані навчальну (`X_train`, `y_train`) та тестову (`X_test`, `y_test`) вибірки у папку `data/processed`.
* **Файли проєкту:**
  * Ноутбук з аналізом: `notebooks/PR02_Musienko_Vadim.ipynb`
  * Очищені дані: `data/processed/iris_cleaned.csv`
  * Звіт та словник класів: `reports/class_mapping.json`
